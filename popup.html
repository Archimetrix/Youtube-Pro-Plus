Cinematic Mode — Read Before Enabling

Cinematic Mode works in both Light & Dark mode on YouTube.

Using Dark Mode? You must turn off Ambient Mode from YouTube's player settings and from this extension panel — otherwise Cinematic Mode won't work as expected.

Please make sure you've read the above before turning this on.

PiP Mode — Read Before Enabling

Automatically floats the video in a small always-on-top window using the browser's native picture-in-picture, then closes it and resumes playback the instant you come back.

There are two separate triggers, and they behave differently:

1) Switching tabs (or minimizing) — works out of the box, no flag needed.

2) Switching to another app while the browser window stays open (just covered) — Chrome doesn't expose this to any webpage's JavaScript at all, so no extension can catch it without browser help. To enable it, turn on both of these flags and restart your browser:

  • chrome://flags/#browser-initiated-automatic-picture-in-picture
  • chrome://flags/#auto-picture-in-picture-on-window-occluded

Brave / Edge / Opera / Vivaldi: swap chrome for your browser's scheme, e.g. brave://flags/...

Heads up: Google is still gradually rolling this pair out server-side, so even with both flags on it may not trigger yet on every install — that's a Chrome-side limitation, not something this extension controls.

Either way, PiP Mode still works without any flags — just click the PiP button on the player to pop it out manually anytime.
